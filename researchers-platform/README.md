# منصة مساعدة الباحثين

منصة أكاديمية مجانية للتدريسيين والباحثين وطلبة الدراسات العليا: 18 خدمة تعمل مباشرة في المتصفح، بلا تسجيل وبلا خادم.

## الخدمات

| القسم | الخدمة |
|---|---|
| المجلات والنشر | فحص المجلة قبل النشر · اكتشف مجلات تخصصك · قائمة التحقق قبل الإرسال |
| فحص البحوث والمراجع | التحقق من ورقة (سحب/تصحيح) · فحص قائمة المراجع · مولّد التوثيق (APA, IEEE, Harvard, MLA, Vancouver, Chicago, BibTeX) · البحث في الدراسات السابقة · بحث كتاب بـ ISBN |
| الباحث والترقية | ملف الباحث ومؤشراته (ORCID) · حاسبة h / i10 / g · حاسبة نقاط الترقية القابلة للتخصيص |
| الدراسات العليا والإحصاء | حجم العينة · كرونباخ ألفا · الإحصاء الوصفي · المخطط الزمني للرسالة |
| أدوات الكتابة | محلل النص والملخص · قياس التشابه بين نصين · باني عبارة البحث Boolean |

## التشغيل

موقع ثابت بلا خطوة بناء. افتح `index.html` عبر أي خادم ملفات:

```bash
python3 -m http.server 8000   # ثم افتح http://localhost:8000
```

للنشر: ارفع المجلد كما هو إلى GitHub Pages أو Netlify أو أي استضافة ثابتة.

## مصادر البيانات

Crossref (البحوث والمجلات والاستشهادات، ومعها سجل Retraction Watch) · DOAJ · ORCID · Open Library.
كلها واجهات مفتوحة تُستدعى من متصفح الزائر مباشرة ولا تحتاج مفاتيح.

## حدود معروفة

- فهرسة Scopus/Clarivate وأرباع المجلات بيانات مملوكة غير متاحة في المصادر المفتوحة؛ المنصة تضع روابط التحقق الرسمية بدلاً من تخمينها.
- حاسبة نقاط الترقية لا تتضمن قيماً رسمية جاهزة؛ يدخل المستخدم القيم من نص التعليمات النافذة في مؤسسته.
- أعداد الاستشهادات من Crossref وقد تقلّ عن Scopus و Google Scholar.

## البنية

```
index.html              الهيكل العام
assets/style.css        التصميم (فاتح/داكن، متجاوب، RTL)
assets/app.js           التوجيه والمساعدات المشتركة
assets/tools-online.js  أدوات البيانات الحيّة
assets/tools-local.js   الحاسبات وأدوات الكتابة
```

لإضافة خدمة جديدة: استدعِ `tool({ id, cat, title, desc, render })` في أحد ملفي الأدوات.

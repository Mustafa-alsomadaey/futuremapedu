# منصة مساعدة الباحثين

منصة أكاديمية مجانية للتدريسيين والباحثين وطلبة الدراسات العليا: 33 خدمة تعمل مباشرة في المتصفح، بلا تسجيل وبلا خادم.

## الخدمات

| القسم | الخدمة |
|---|---|
| الترقية العلمية | حاسبة الترقية وفق تعليمات (10) لسنة 2025 · حاسبة تعليمات (167) لسنة 2017 · نص التعليمات وجداول النقاط · مسار المعاملة · حاسبة نقاط مخصّصة |
| المجلات والنشر | فحص المجلة · اكتشاف مجلات التخصص · اقتراح مجلة للبحث · دور النشر · دليل المجلات العراقية (DOAJ) · قائمة التحقق قبل الإرسال |
| فحص البحوث والمراجع | تقرير جودة البحث · التحقق من السحب · فحص المراجع · فحص عنوان البحث · استمارة الرصانة العلمية · فحص الباحثين المشاركين · مولّد التوثيق · البحث في الدراسات السابقة · بحث كتاب بـ ISBN |

| أدوات الكتابة | كشف العبارات المشوّهة · محلل النص · قياس التشابه بين نصين · باني عبارة البحث Boolean |
| المؤتمرات والروابط | فحص مؤتمر قبل المشاركة · دليل الروابط الرسمية |

## التشغيل

موقع ثابت بلا خطوة بناء. افتح `index.html` عبر أي خادم ملفات:

```bash
python3 -m http.server 8000   # ثم افتح http://localhost:8000
```

للنشر: ارفع المجلد كما هو إلى GitHub Pages أو Netlify أو أي استضافة ثابتة.

## مصادر البيانات

Crossref (ومعه سجل Retraction Watch) · DOAJ · ORCID · DataCite · Open Library — واجهات مفتوحة تُستدعى من متصفح الزائر ولا تحتاج مفاتيح.

ملفات محلية في `data/`:
- `law-2025.txt` و `law-2017.txt` و ملفا PDF: النص الرسمي لتعليمات الترقيات العلمية العراقية.
- `beall.json`: قائمة Beall للناشرين المحتمل أنهم مفترسون (من beallslist.net، مرجع تحذيري غير رسمي).

## حدود معروفة

- فهرسة Scopus/Clarivate وأرباع المجلات بيانات مملوكة؛ المنصة تضع روابط التحقق الرسمية بدلاً من تخمينها.
- نقاط الكتاب المؤلَّف تُدخل يدوياً ضمن المدى الوارد في الجدول (3–10 في 2025، 5–25 في 2017).
- حاسبة المناقشة لاستمارة الماجستير فقط.
- غير متوفر لعدم وجود مصدر مفتوح: أرشيف الكتب الوزارية، دليل المؤتمرات العراقية والعالمية، تصنيفات الجامعات العراقية ونشاطها العلمي.

## البنية

```
index.html              الهيكل العام
assets/style.css        التصميم (فاتح/داكن، متجاوب، RTL)
assets/app.js           التوجيه والمساعدات المشتركة
assets/tools-promotion.js  حاسبات الترقية والتعليمات ومسار المعاملة
assets/tools-online.js  أدوات البيانات الحيّة
assets/tools-extra.js   تقرير الجودة، اقتراح المجلة، استمارة الرصانة…
data/                   نصوص التعليمات وقائمة Beall
assets/tools-local.js   الحاسبات وأدوات الكتابة
```

لإضافة خدمة جديدة: استدعِ `tool({ id, cat, title, desc, render })` في أحد ملفي الأدوات.
